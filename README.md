# Kieler Woche der Mathematik 2026 - Markowketten
Dies ist eine JupyterLab-basierte Plattform für interaktive Python-Übungen zu Markowketten.

---

### So funktioniert es
1. Öffne das gewünschte Notebook.
2. Klicke oben im Menü auf **Run ➜ Run All Cells** und warte, bis alle Stationen geladen sind.
3. Bearbeite die einzelnen Stationen und Aufgaben im Notebook. Die Reihenfolge der Stationen ist (nahezu) beliebig. Die Kennzeichnungen *Leicht*, *Schwerer* und *Schwer* helfen bei der Einordnung.
4. Speichere mit **Strg + S**. Lade dein bearbeitetes Notebook am Ende der Übung als .ipynb-Datei herunter, indem du im Dateibrowser links mit der rechten Maustaste auf dein Notebook klickst und **Download** auswählst.
