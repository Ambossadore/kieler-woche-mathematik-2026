Dies ist eine Browser-basierte Plattform für interaktive Python-Übungen.

### So funktioniert es

1. Öffne das gewünschte Notebook.
2. Führe Python-Zellen mit Shift + Enter aus.
3. Verändere die vorgegebenen Parameter.
5. Lade dein bearbeitetes Notebook am Ende der Übung als .ipynb-Datei herunter.
